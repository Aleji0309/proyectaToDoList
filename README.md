# To-Do List - Alura LATAM Challenge  

## Description  
This project was developed as part of an **Alura LATAM challenge**. It is a **simple and functional To-Do List** built with **HTML, CSS, and JavaScript**, allowing users to add, remove, and manage tasks efficiently.  

The main objective was to practice **DOM manipulation, event handling, and local storage** to create an interactive and user-friendly task manager.
