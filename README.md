## 📋 Project Description

This project is a simple task management app that lets users:

- Add new tasks  
- Mark tasks as completed  
- Delete individual tasks  
- Clear the entire task list

All tasks are managed in the browser without external storage. This is a great project to practice DOM manipulation, input validation, and interactive UI behavior using plain JavaScript.

## 📌 Key Features

- Real-time task creation and deletion  
- Visual feedback for completed tasks  
- Simple and intuitive layout  
- Fully responsive on mobile and desktop  
- Lightweight and fast-loading

## 🚀 How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/Aleji0309/proyectaToDoList.git
````

2. Navigate to the folder:

```bash
cd proyectaToDoList
```

3. Open the `index.html` file in your browser.

> This is a static project — no build tools required.
